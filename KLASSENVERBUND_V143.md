# v1.4.3 – PA Klassenverbund – Zuordnung Beobachter/Aufgabe

Optionales, eingeklapptes Modul in `tool.html`, zunächst deaktiviert.

- In jedem Arbeitskreis genau zwei Aufgaben auswählen.
- Für Block A je Arbeitskreis eine Aufgabe auswählen; die jeweils andere wird Block B.
- Für jede Gruppe einer Klasse die zwei Beobachter aus den Excel-Spalten `1. Beobachter` und `2. Beobachter` den Blöcken A/B zuordnen. Voreinstellung: erster Beobachter A, zweiter B. `Tauschen` erlaubt einen Klick pro Gruppe.
- Die Auswahl wirkt auf alle sechs BB je Schüler und auch im Einzeldruck. BKB und SE unverändert.
- Fehlende Gruppennummer, fehlende oder identische Beobachter oder nicht genau zwei Aufgaben je AK: BB-Beobachterfeld bleibt leer.
- Wenn mehrere Schüler derselben Gruppe verschiedene Beobachterpaare haben, erscheint eine Warnung.
- Daten werden nur im Browser-RAM gehalten. Nach einem neuen Import werden die Gruppenzuordnungen zurückgesetzt.
- **Hinweis:** Die Zuordnung setzt die bisherige Excel-Paarung pro Gruppe voraus; sie übernimmt keine Zeitpläne automatisch.

Vor produktivem Einsatz unbedingt einen BB-Probedruck für zwei Gruppen und beide Aufgabenblöcke machen.
