# PA-Drucktool – vollständiges Paket mit echter Blanko-SE

Die Datei `Vorlagen/Vorlage Selbsteinschaetzungsbogen.pdf` wurde durch die vom Nutzer bereitgestellte **unbearbeitete Blanko-SE** ersetzt. Die zuvor im GitHub-Projekt enthaltene Vorlage hatte bereits feste Durchstreichungen und war für eine optionale Anpassung ungeeignet.

## Neue Einstellung

`Selbsteinschätzung (ohne PC-Profil-Test) anpassen?` – standardmäßig aktiviert.

- **Aktiviert:** Die PDF-Erstellung zeichnet mittige Striche über die Merkmalsnamen und jeweils fünf Bewertungsfelder für Präsentationsfähigkeit, Informationstechnische Fähigkeit, Konzentrationsfähigkeit, Räumliches Vorstellungsvermögen, Merkfähigkeit und Schlussfolgerndes Denken.
- **Deaktiviert:** Unbearbeitete Blanko-SE ohne Striche.
- Gilt für Sammeldruck und Einzeldruck.
- BB und BKB unverändert.

## Installation auf GitHub

ZIP entpacken und **alle Dateien und Ordner** in das öffentliche Repository übernehmen (vorhandene Dateien ersetzen). Ordnerstruktur einschließlich `Vorlagen/` und `js/` erhalten. Anschließend GitHub Pages neu laden (gegebenenfalls Strg+F5).

**Hinweis:** PDF-Vorlagen sind im öffentlichen GitHub-Repository öffentlich abrufbar. Wenn das nicht gewünscht ist, dürfen die PDFs nicht in das öffentliche Repository hochgeladen werden.

Die Vorlage wurde auf Seitenformat und Formularfelder geprüft. Die Position der Striche muss mit einer erzeugten Test-PDF visuell kontrolliert werden.
