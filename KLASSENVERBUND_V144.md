# v1.4.4 – Automatischer Gruppenwechsel

- Standard: ungerade Gruppen (1,3,5) → Block A = 1. Beobachter, Block B = 2. Beobachter.
- Gerade Gruppen (2,4,6) → Block A = 2. Beobachter, Block B = 1. Beobachter.
- Namen weiterhin aus Excel, Aufgabenblöcke weiterhin je eine Aufgabe aus AK I, II und III.
- Zuordnung bleibt jederzeit manuell über die Auswahllisten oder „Tauschen“ änderbar.
- Keine automatische Änderung, wenn die Excel-Liste neu geladen wird, bevor die neue Gruppenzuordnung neu aufgebaut wird.
- Optionaler Klassenverbund bleibt standardmäßig deaktiviert und eingeklappt.
- BKB, SE und übrige Funktionen unverändert.

**Test:** Bei einer Gruppe 1/2 mit identischem Beobachterpaar muss derselbe Beobachter bei den Aufgaben seines Blocks auf beiden Gruppen-BB erscheinen.
