PA-Drucktool: PDF-Schülerliste (SaxSVS-Format) – TESTVERSION

Diese vier Dateien im Hauptverzeichnis des GitHub-Pages-Repositories ersetzen/ergänzen:
- tool.html (ersetzen)
- app.js (ersetzen)
- pdf-engine.js (ersetzen)
- saxsvs-import.js (NEU)

Nutzung:
1. Tool öffnen und "PDF-Schülerliste (SaxSVS-Format) importieren" aufklappen.
2. Original-PDF aus SaxSVS auswählen; optional gemeinsames PA-Datum angeben.
3. "PDF-Schülerliste einlesen" anklicken.
4. ERKANNTE NAMEN UNBEDINGT PRÜFEN, dann normal oder im Expertenmodus drucken.

Die PDF muss echten, extrahierbaren Text enthalten. Gescannte oder durch Schwärzung
in ein Bild umgewandelte PDFs können nicht eingelesen werden.

WICHTIG: Der Importer wurde mit einer künstlich erstellten Text-PDF erfolgreich
getestet, aber noch NICHT mit einer ungeschwärzten Original-SaxSVS-PDF.
Die erste Erprobung mit einer Originaldatei ist daher notwendig.
Es werden keine Schülerdaten an einen Server gesendet.

Excel-Import und Testdatei laden bleiben erhalten.
